# Smart Irrigation System for Grape Cultivation

This project was developed under the New Age Innovation Network (NAIN) initiative and received funding support from the Government of Karnataka.

The system uses IoT devices and Machine Learning techniques to monitor soil and environmental conditions and automate irrigation decisions for grape cultivation.

## Features

* Real-time soil moisture monitoring
* Environmental data collection
* Automated irrigation control
* Cloud-based data storage
* Machine Learning-based decision support

## Technologies Used

* ESP32
* Raspberry Pi 5
* Firebase
* Python
* IoT Sensors
* Machine Learning
